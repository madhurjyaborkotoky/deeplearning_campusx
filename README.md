## 👋 About This Repository

Welcome to my **Deep Learning learning repository**.

This repository contains the code, experiments, implementations, and practice work that I build while learning Deep Learning through the **100 Days of Deep Learning** playlist by **CampusX**.

Instead of simply watching lectures, I am following a **learn → code → experiment → debug → understand → implement** approach.

Every concept that I find useful is implemented and tested in my own development environment using **Python, VS Code, Git, and GitHub**.

## 🧪 How I Work

For each topic, I try to follow this workflow:

```bash
# 1. Learn
Watch → Understand → Take Notes

# 2. Implement
Write the concept from scratch

# 3. Experiment
Change parameters
Try different datasets
Break things intentionally

# 4. Debug
Read the error
Search for the cause
Fix it
Understand the fix

# 5. Document
Keep useful implementations
Record important observations

# 6. Commit
git add .
git commit -m "Add implementation for <topic>"
git push
```

The objective is to make sure that I can **reproduce the concept independently**, rather than simply recognizing it from a lecture.

## 🐛 The Debugging Philosophy

One of the biggest parts of this repository is learning how to deal with things that **don't work**.

When something breaks, I try not to immediately copy a solution.

Instead:

```text
ERROR
  ↓
READ THE ERROR
  ↓
IDENTIFY THE SOURCE
  ↓
UNDERSTAND THE REASON
  ↓
TRY A FIX
  ↓
TEST AGAIN
  ↓
DOCUMENT WHAT I LEARNED
```

Because knowing how to debug is just as important as knowing how to write code.
